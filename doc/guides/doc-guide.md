# Guides guide

- Use the imperative in headings and text (like this)
- Write the headings so that together they form a summary
- Describe each step on one line
- Format `screen elements`, `commands` and `code` as code.
- Put shell commands into a bash code block

```bash
ls -la
```

- Describe step sequences as sentences with a blank line in between
- Write in short and clear sentences
