# README Guide

- If not yet present, create a `README.md` and a `README.de.md`
- Read `doc/templates/readme-template.md` and revise the `README.md`
- Write concise, short, clearly understandable
- Write `README.de.md` first when the prompt is written in German
- Write `README.md` first when the prompt is written in English
